# Web-Design-Experiment-1

## Experiment 01

### Aim
To create a GitHub repository, create branches,
merge changes and host a static website using
GitHub Pages.

### Resources Used
- Visual Studio Code
- GitHub
- HTML
- CSS
- GitHub Pages
- Web Browser

### Project Description
This project contains a basic webpage created
using HTML and CSS. It demonstrates the use
of GitHub for version control and website hosting.

### Files
- index.html - Main webpage
- README.md - Project information

### Hosting
The website is hosted using GitHub Pages.
